## ✨ O que é

O **KzApp** ajuda jovens angolanos a controlar o dinheiro que recebem e gastam, criando objetivos de poupança — tudo **offline**, **sem anúncios** e **sem servidor**.

- 📴 **100% offline**
- 🚫 **Zero anúncios**
- 🔒 **Dados só no teu telemóvel**
- 🇦🇴 **Feito para Angola**

---

## 🛠️ Stack

- **React Native + Expo SDK 57**
- **JavaScript**
- **React Navigation**
- **AsyncStorage**
- **Fonte Inter**
